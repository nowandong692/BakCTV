# 박CTV

가족끼리 쓰는 실시간 촬영·모니터 앱입니다.
한 폰으로 촬영하고, 다른 폰에서 실시간으로 영상과 소리를 보고 들을 수 있습니다.

- **웹 주소**: https://nowandong692.github.io/BakCTV/ (대소문자 그대로 입력)
- **촬영 폰용 APK**: https://github.com/nowandong692/BakCTV/releases/latest/download/BakCTV.apk

## 어떤 폰에 무엇을 설치하나요?

| | 촬영 폰 | 보는 폰 |
|---|---|---|
| 설치 방법 | **APK** 설치 | 웹 주소에서 **"📲 앱으로 설치하기"** |
| 화면을 꺼도 촬영 유지 | ✅ 됨 | – |
| 아이폰 | ❌ (안드로이드만) | ✅ Safari → 공유 → 홈 화면에 추가 |

### 왜 촬영 폰은 APK 여야 하나요?

- **웹에서 "앱으로 설치하기"로 설치한 앱**은 홈 화면 아이콘이 생기지만 실제로는 크롬 안에서 동작합니다.
  안드로이드가 화면이 꺼지면 카메라를 막기 때문에 **화면이 꺼지면 촬영이 멈춥니다.**
  (화면을 켜 두고 🌙 **화면 가리기** 버튼을 쓰면 계속 촬영할 수 있습니다.)
- **APK 로 설치한 앱**은 알림줄에 "박CTV 촬영 중" 알림을 띄워 두기 때문에 **화면을 꺼도 촬영이 계속됩니다.**

> 촬영 폰에 두 가지를 모두 설치하면 같은 이름·아이콘의 박CTV 가 두 개 생겨 헷갈립니다.
> 촬영 폰에는 **APK 하나만** 설치하세요.

## 사용법

1. 두 폰에 **같은 방 코드**를 입력합니다.
   - 10자 이상, 글자와 숫자를 섞어야 합니다. (예: `박씨네거실-별빛3829`)
   - 방 코드가 비밀번호 역할을 하니 가족끼리만 공유하세요.
2. 촬영 폰: **이 기기로 촬영하기**
3. 보는 폰: **다른 기기 영상 보기**

### 촬영 폰 화면

| 버튼 | 기능 |
|---|---|
| 🔄 카메라 전환 | 전면 ↔ 후면 |
| 🎤 소리 켜짐/꺼짐 | 촬영 폰 마이크 켜기·끄기 |
| 🌙 화면 가리기 | 촬영은 계속, 화면만 검게. **두 번 누르면** 돌아옴 |
| ■ 종료 | 촬영 종료 |

- 위쪽 **시청 N명**: 지금 보고 있는 기기 수 (모르는 숫자가 보이면 방 코드를 바꾸세요)
- 위쪽 **🎤▮▮▯▯▯**: 마이크에 소리가 들어오는지 표시

### 움직임 감지 (촬영 앱)

- 촬영 앱의 **👁 움직임 감지** 버튼으로 민감도를 바꿉니다: 끔 → 낮음 → **보통**(기본) → 높음
  - 어두운 곳에서 작은 움직임까지 잡으려면 **높음**
- 움직임이 감지되면 보는 폰에 **빨간 테두리 + 움직인 부분 박스 + "⚠ 움직임 감지" 배너**, **알림음 2번 + 진동**(안드로이드)
- 보는 폰의 **🔔 알림** 버튼으로 알림음·진동을 켜고 끌 수 있습니다 (화면 표시는 항상)
- 보는 폰이 화면을 열어 두고 있을 때만 알림이 옵니다 (잠긴 폰에는 알림 불가)
- 동작 방식: 영상을 작은 흑백 화면으로 줄이고 가우시안 블러로 노이즈를 누른 뒤 배경과 비교.
  기준값은 화면 노이즈 수준에 맞춰 자동 조정되고, 조명이 한꺼번에 바뀌는 경우(불 켜기·카메라 전환·색상 반전)는 무시합니다.

### 보는 폰 화면

| 버튼 | 기능 |
|---|---|
| 🔊 소리 끄기/켜기 | 촬영 폰 소리 듣기 |
| 🎙 말하기 | 누르면 내 목소리가 촬영 폰 스피커로 나감, 다시 누르면 끝 |
| 🔔 알림 켜짐/꺼짐 | 움직임 감지 시 알림음·진동 |
| ⛶ 전체화면 | 영상 크게 보기 |

- 촬영이 끊겨도 3초마다 자동으로 다시 연결합니다.

## 촬영 폰 (APK) 설치·사용

1. 촬영 폰에서 위의 **APK 링크**를 열어 다운로드 → 설치
   - "출처를 알 수 없는 앱" 허용을 묻으면 허용합니다.
2. 처음 실행하면 다음을 모두 **허용**합니다.
   - 카메라, 마이크, 알림
   - "배터리 사용량 최적화 중지" (절전 때문에 연결이 끊기는 것을 막습니다)
3. 방 코드 입력 → **이 기기로 촬영하기** → 이제 **전원 버튼으로 화면을 꺼도** 촬영이 계속됩니다.
4. 끝낼 때: 앱의 **■ 촬영 종료** 버튼, 또는 알림의 **종료** 버튼.
   - 앱을 닫거나 최근 앱 목록에서 밀어도 촬영은 계속됩니다. 알림이 떠 있으면 촬영 중입니다.
- 앱 안의 **다른 기기 영상 보기 (웹)** 버튼은 웹 주소를 크롬으로 엽니다.

### 장시간 촬영 팁

- 충전기 연결은 필수
- 폰이 뜨거워질 수 있으니 케이스를 빼고 통풍되는 곳에
- 처음 설치하면 화면을 끈 상태로 10분쯤 시험해 보세요.

## 문제 해결

| 증상 | 해결 |
|---|---|
| 화면을 끄면 촬영이 멈춤 | 설정 → 애플리케이션 → 박CTV → 배터리 → **제한 없음**. 삼성 폰은 설정 → 배터리 → 백그라운드 사용 제한 → **절전 예외 앱**에 박CTV 추가 |
| 소리가 안 들림 | 보는 폰의 🔊 버튼과 **미디어 볼륨** 확인. 소리 막대가 촬영 폰에서 안 움직이면 마이크 권한 확인 |
| "앱으로 설치하기"가 안 보임 | 크롬 **일반 창**(시크릿 X)에서 주소를 직접 입력해 열기. 카톡 등 앱 안 브라우저에서는 메뉴 → "Chrome 에서 열기" |
| 밖(LTE)에서 연결이 안 됨 | 통신사 네트워크 환경에 따라 생길 수 있음 (TURN 서버 추가 필요) |

## 개발자용

### 저장소 구조

- `web/` — 웹 버전 박CTV (촬영·보기 공용 화면). main 에 올리면 **GitHub Pages** 로 자동 배포
- `app/` — 촬영 폰용 안드로이드 앱. 카메라·마이크와 WebRTC 전송을 앱이 직접 처리(포그라운드 서비스)해서 화면이 꺼져도 촬영 유지.
  웹 시청자와는 PeerJS 규칙으로 연결되므로 보는 쪽은 웹앱 그대로 사용
  - 처음에는 WebView 로 웹 화면을 띄웠으나, 안드로이드의 크롬 엔진은 앱 화면이 사라지면 카메라를 해제하도록 되어 있어 화면 꺼짐 촬영이 불가능 → 직접 구현으로 변경
- `.github/workflows/deploy-web.yml` — 웹 배포
- `.github/workflows/build-apk.yml` — APK 빌드 후 **Releases** 에 `BakCTV.apk` 로 배포

### 업데이트 방식

- **웹 수정** (`web/`): 올리면 GitHub Pages 에 자동 배포. 보는 폰은 다음 실행 때 자동 반영
- **촬영 앱 수정** (`app/`): 올리면 APK 가 새로 빌드되고 버전이 자동으로 올라갑니다. 같은 링크로 받아 **덮어쓰기 설치**
- ⚠️ 방 코드 규칙·연결 ID 계산(`RoomCode.kt` ↔ `web/index.html`의 `roomId`)과 PeerJS 메시지 형식은 **웹과 앱이 항상 같아야** 서로 연결됩니다.
- 웹 주소가 바뀌면 `app/src/main/res/values/strings.xml` 의 `app_url` 을 고칩니다.

### GitHub 설정 (최초 1회, 완료됨)

- **Settings → Pages → Source**: `GitHub Actions`
- **Settings → Secrets and variables → Actions**: `KEYSTORE_PASSWORD`, `KEYSTORE_BASE64`
  - APK 서명 키입니다. 항상 같은 키로 서명해야 덮어쓰기 업데이트가 됩니다. **잃어버리지 마세요.**

### 기술 메모

- 영상·소리는 WebRTC 로 기기끼리 직접(P2P, 암호화) 전송. 연결 중계는 PeerJS 공개 서버
- 방 코드는 PBKDF2(20만 회)로 변환한 값만 연결 ID 로 사용 — 원래 코드는 서버로 전송되지 않음
- 안드로이드 8.0 이상, targetSdk 34
